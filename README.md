PROJEKT INFO

Dette projekt består af en frontend og en backend, som begge startes samtidig.

---

SETUP

1. Åbn terminal i projektmappen

2. Installer dependencies:

* npm install (i projektmappen)
* cd backend → npm install
* cd frontend → npm install

3. Kør projektet fra projektmappen:

* npm run dev  (dette starter både backend og frontend delen)
